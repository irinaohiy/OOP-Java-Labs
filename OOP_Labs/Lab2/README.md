## Розрахунок варіанта
Параметри завдання визначені на основі порядкового номера у списку групи (№7) за допомогою операції остачі від ділення.

| Параметр | Формула | Результат | Значення для реалізації |
| :--- | :--- | :--- | :--- |
| **C5** (Дія) | $7 \mod 5$ | **2** | Математична операція: **Додавання ($C = A + B$)** |
| **C7** (Тип) | $7 \mod 7$ | **0** | Тип елементів матриці: **double** |
| **C11** (Обробка) | $7 \mod 11$ | **7** | **Min** у парних стовпцях, **Max** у непарних стовпцях |

## Завдання
1. Створити код, який динамічно генерує матриці $A$ та $B$ заданого розміру та заповнює їх випадковими числами.
2. Реалізувати метод математичного додавання матриць дійсних чисел ($C = A + B$).
3. Написати алгоритм обробки отриманої матриці $C$: знайти найменші елементи в парних стовпцях та найбільші елементи в непарних стовпцях, після чого обчислити їхню підсумкову суму.

## Опис виконаної роботи

У ході виконання роботи було реалізовано наступні програмні рішення:

1. **Модульна архітектура програми:**
   * Програму спроєктовано відповідно до принципів чистого коду (Clean Code) та розбито на окремі статичні методи: `createMatrix` (генерація), `addMatrices` (додавання), `calculateExtremumsSum` (пошук за варіантом) та `printMatrix` (виведення).

2. **Динамічне заповнення та типізація:**
   * Відповідно до коефіцієнта $C7=0$, для матриць використано двовимірні масиви типу `double[][]`. Заповнення елементів дійсними дробовими числами виконується динамічно за допомогою класу `Random` та методу `nextDouble()`.

3. **Математична валідація:**
   * Оскільки операція додавання ($C5=2$) можлива лише для матриць однакових розмірностей, у методі `addMatrices` впроваджено жорстку перевірку рівності кількості рядків (`length`) та стовпців (`[0].length`). При спробі передати несумісні дані матимемо виняток `IllegalArgumentException`.

4. **Вертикальний вектор обходу елементів:**
   * Для реалізації умов варіанта $C11=7$ було змінено стандартний порядок обходу матриці: зовнішній цикл ітерується по стовпцях (`j`), а внутрішній - по рядках (`i`). За допомогою оператора остачі від ділення `j % 2 == 0` стовпці діляться на парні (де алгоритм фіксує мінімум) та непарні (де фіксується максимум). Всі знайдені локальні екстремуми додаються в єдину фінальну суму.

## Результати
Програма успішно ініціалізує початкові дані, проводить математично безпечне додавання матриць та знаходить підсумкову суму екстремумів по стовпцях. Результати виводяться у консоль у вигляді акуратної та вирівняної матричної сітки завдяки специфікатору форматування `%10.4f` (округлення до 4 знаків після коми).
