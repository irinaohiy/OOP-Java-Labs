## Завдання
1. Створити користувацький клас `Furniture` згідно з отриманим варіантом, який містить не менше 5 полів різних типів даних.
2. Забезпечити принципи інкапсуляції (закриті поля, доступ через геттери), написати конструктор класу та перевизначити метод `toString()`.
3. Створити виконавчий клас із масивом об'єктів (каталогом меблів).
4. Реалізувати багаторівневе сортування масиву об'єктів за двома параметрами: спочатку за **ціною** (Price) - за зростанням; за умови однакової ціни - за **вагою** (Weight) - за спаданням.
5. Написати метод пошуку об'єкта в масиві, який повністю тотожний заданому за всіма п'ятьма полями.

## Опис виконаної роботи

У ході виконання роботи було реалізовано наступні об'єктно-орієнтовані рішення:

1. **Інкапсуляція та проєктування класу:**
   * Спроєктовано клас `Furniture`, що містить 5 характеристик: `name` (String), `material` (String), `price` (double), `weight` (double), `durabilityYears` (int). Всі поля оголошені з модифікатором `private`, що повністю ізолює внутрішній стан об'єкта. Доступ для читання полів реалізовано через публічні методи-геттери.

2. **Багаторівневе сортування масиву об'єктів:**
   * Для впорядкування каталогу використано вбудований метод `Arrays.sort()` у парі з кастомним об'єктом порівняння `Comparator`. Алгоритм працює у два етапи: спочатку порівнює ціни елементів меблів. Якщо ціни однакові, у гру вступає другий критерій - порівняння ваги. Для забезпечення сортування ваги за спаданням, параметри порівняння у методі `Double.compare` поміняні місцями (`f2` порівнюється з `f1`).

3. **Глибоке порівняння полів (Deep Comparison):**
   * Для виконання умови тотожного пошуку було створено метод `findIdentical()`. На відміну від стандартного порівняння посилань пам'яті (`==`), цей метод послідовно аналізує вміст кожного з п'яти полів об'єкта, використовуючи `equals()` для текстових рядків та `Double.compare()` для числових полів. Метод повертає об'єкт лише при 100% збігу інформації.

4. **Форматоване представлення об'єкта:**
   * Метод `toString()` перевизначено з використанням `String.format()`, що дозволяє автоматично приводити об'єкти меблів до красивого інформативного текстового вигляду при виведенні в консоль.
