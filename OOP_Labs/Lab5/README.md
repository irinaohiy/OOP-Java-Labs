   - **Речення** повинно складатися з масиву слів та розділових знаків.
   - **Текст** повинно складатися з масиву речень (`Sentence[]`).
3. Виконати обов'язкову нормалізацію даних: замінити будь-яку послідовність табуляцій та пробілів одним єдиним пробілом.

## Опис виконаної роботи

У ході розробки було спроєктовано глибоку об'єктну модель тексту, де кожен рівень абстракції надійно інкапсулює свої дані та відповідає принципу відношення композиції:

1. **Ієрархія компонентів програми:**
   * **Letter:** Найменша атомарна одиниця системи, яка інкапсулює примітивний символ `char`.
   * **Word:** Складається з масиву об'єктів `Letter[]`. Конструктор динамічно розбирає вхідний рядок на об'єкти літер. Перевизначено метод `toString()` для зручного відновлення текстового значення.
   * **Sentence:** Використовує гетерогенний масив типу `Object[]`. Це дозволяє реченню одночасно зберігати у правильній послідовності як складні об'єкти `Word`, так і символи пунктуації чи пробіли, представлені типом `String`. Впроваджено метод `getWords()` для фільтрації та вилучення суто об'єктів слів.
   * **Text:** Найвищий рівень ієрархії, що керує масивом об'єктів `Sentence[]`.

2. **Попередня нормалізація тексту:**
   * У конструкторі класу `Text` реалізовано обов'язкове очищення вхідного потоку даних за допомогою методу `replaceAll("[\\t ]+", " ")`. Це гарантує, що будь-яка хаотична кількість послідовних пробілів або знаків табуляції буде коректно стиснута в один стандартний пробіл перед побудовою дерева об'єктів.

3. **Реалізація логіки сортування:**
   * Програма послідовно збирає всі об'єкти `Word` з усього створеного дерева класів `Text`.
   * Реалізовано фільтрацію слів на голосну літеру (як латиницею, так і кирилицею в обох регістрах) за допомогою рядка-довідника та методу `indexOf()`.
   * Написано кастомний лямбда-компаратор для сортування об'єктів `Word` за їхньою другою літерою (індекс `1`). У компараторі передбачено захист від помилки виходу за межі рядка для однолітерних слів.

## Результати
Програма повністю та безпомилково реалізує об'єктно-орієнтовану модель текстового документа. Вхідний рядок із зашумленими пробілами та табуляціями успішно нормалізується, каскадно розбивається на систему пов'язаних об'єктів, після чого програма виконує сортування слів згідно з вимогами. Вивід результату у консоль здійснюється шляхом звернення до перевизначених методів об'єктів.
